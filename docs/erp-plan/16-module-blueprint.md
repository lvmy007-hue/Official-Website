## 怎么读这份蓝图

**每个板块写五样东西：**

1. 菜单树：在现有路由的基础上标出新增和调整。
2. 页面：每页用哪种骨架。骨架代号见 15 章第 5 节：列表、宽表、整页详情、流程、配置。
3. 详情页结构：页签或锚点各是什么。
4. 字段与口径：要新增或统一的指标和口径。
5. 接口与优先级：接口路径是建议，写进 `api.md` 时按现有命名规范调整。

**标记：**

- 【有】：已有页面，只做改版；
- 【新】：新增页面；
- 【改】：结构有较大调整。

## 2. 统计分析

### 2.1 商品表现【新】`/app/analytics/product-performance`（建议-11，P1 大）

**骨架：** 宽表，这是全站宽表的示范页。

**维度切换：** ASIN、父 ASIN、SKU、店铺、负责人、品牌、品类。同一套指标按所选维度重新聚合。

**列分组：**

| 分组 | 内容 |
|---|---|
| 商品信息 | 固定在左侧 |
| 销售 | 销量、订单量、销售额、净销售额、均价、B2B |
| 流量 | Sessions、PV、转化率、购物车赢得率 |
| 广告 | 花费、广告销售额、ACOS、TACOS、ACoAS、ASoAS、CPC、广告订单占比 |
| 利润 | 毛利、毛利率、ROI。按字段权限降级，没有权限时整组不返回 |
| 库存 | FBA 可售、在途、可售天数 |
| 售后 | 退货率、退款率、评分 |

**每个指标列的四种显示：** 本期值、上期值、涨跌（双行单元格）、迷你趋势。

**汇总行：** 合计或平均，由服务端汇总。

**行展开：** 父 ASIN 展开子体。

**口径：** 所有列头的问号都读取指标口径字典。字典增加两个字段：`reconcileWith`（应该和哪个页面对数）、`mismatchReasons`（可能对不上的原因）。

**接口：**

| 接口 | 用途 |
|---|---|
| `POST /analytics/product-performance/query` | 维度、指标、筛选、排序、游标 |
| `.../summary` | 汇总行 |
| `.../trend` | 批量获取迷你趋势，异步加载 |

**与旧页面的关系：** 和"ASIN 与父体分析""刊登表现"重叠的列表视图，逐步改成跳转到这里，但保留旧页面里独有的分析区块。

**退货周期与跨月的口径（新增到 `metrics.md`）：**

- 退货周期 = 退货日期 − 下单日期（也可以选发货日期），按可配置的天数段分桶，同时给出中位数。
- 跨月退货占比 = 下单月和退货月不同的退货件数 ÷ 退货总件数。另给一张"下单月 × 退货月"的矩阵。
- 队列退货率：分子和分母都按同一批订单的下单月统计。与现有"按退货日"的口径并排显示，并写清两者各自的用途。

### 7.1 毛利润公式和口径可配置（已确认放开"同名指标只有一个口径"，P1 中）

| 页面 | 内容 |
|---|---|
| 利润公式 `/app/finance/profit-formula`【新】 | 一张勾选表，每个利润项目一行。每行可以设置是否计入毛利润，以及是否作为毛利率的分母。页面顶部用彩色标签显示当前公式。修改要走审批，沿用 P2b-15 的财务口径审批；生效后形成一个新的口径版本 |

约束（防止"两张报表对不上"）：

- 每个企业同一时刻只有一个生效版本。全站所有页面都用这个版本，不允许不同页面用不同公式。

- 关账快照记录当时的口径版本。已关账月份不受之后的修改影响；需要按新口径重算时，生成差异报告。
- 口径字典里的条目标记为"可配置"，并写明在哪里配置（`configurableAt`）。

- `GET /finance/profit-formula`、`PUT /finance/profit-formula`（提交后进入审批）
- `GET /settings/business-rules`、`PUT /settings/business-rules/:key`
