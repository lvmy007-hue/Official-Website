## 1. 物流追踪接口是否覆盖入仓货件

**官方说法**：Tracking API v2026-01-30 返回"亚马逊供应链中、面向外部渠道的货件"的追踪信息，含预计送达日与里程碑事件；目前仅美国站上线，卖家与供应商均可用。新增了 `proNumber` 参数与 `getShipmentTrackingBatch`（批量），并配套推送类型 `SHIPMENT_TRACKING_MILESTONE_CHANGED`。

**结论**：官方文档没有把"入仓货件（卖家发往亚马逊仓库）"列入覆盖范围。入仓货件的状态、预计送达日、追踪详情，官方给出的来源是 Fulfillment Inbound v2024-03-20 的 `getShipment`（返回状态、发货日、预计送达日、追踪详情、托盘、预约信息），承运商非合作时由卖家用 `updateShipmentTrackingDetails` 回填追踪号。

**处置**：
- 入仓货件的追踪字段以 Fulfillment Inbound 为准，来源标注"入仓接口 / 卖家回填"；
- Tracking API 与里程碑推送作为可选增强，**只有在真实账号实测证明能返回入仓货件时才启用**，未证明前页面不出现该来源；
- 实测由 P2a 入仓货件工作包完成，结果回填本台账。

来源：Tracking API 参考页、SP-API 发布说明、Fulfillment Inbound 创建入仓货件指南。

## 2. 评分与评分数的官方来源

**官方说法**：Customer Feedback API v2024-06-01 提供的是"评论话题洞察"：每个子 ASIN 最正面与最负面各 10 个话题，含提及占比与对星级的影响，以及月度趋势；退货洞察只到类目节点级。美国站可用，数据每周刷新，仅英文；所需角色为品牌分析（Brand Analytics）或卖家洞察（Selling Partner Insights）二者之一。

**结论**：官方**不提供**某个 ASIN 的平均星级与评分数。

**处置**（与你已确认的口径一致）：
- 评论话题：用官方接口取，来源标注"亚马逊客户反馈接口"，更新频率标注"每周"；
- 平均星级、评分数：字段保留，数据由"文件导入"进入，页面逐项标注"来源：导入文件、采集日期、导入人"；无数据时显示正式空状态与导入入口；
- 不抓取亚马逊前台页面。导入模板由我方在 P0-04 中定义（ASIN、站点、平均星级、评分数、采集日期、来源说明）。

来源：客户反馈接口概述与 `getItemReviewTopics` 参考页。

## 3. 销售税报告类型

**官方说法**：销售税报告类型值为 `GET_FLAT_FILE_SALES_TAX_DATA`；仅美国站、仅卖家；输出为制表符分隔的文本；内容每日更新；**不能通过 `createReport` 申请或排程**，必须由卖家在卖家后台"税务文档库"生成，生成后用 `getReports` 按报告类型检索；所需角色为"税务汇缴（受限）"。报告保留期最长 90 天。订单接口 `includedData` 带 `TAX` 时，可取得订单级税务登记、电子发票状态、逐商品的税收取模式（如市场代收代缴）。

**结论与处置**：
- 销售税导入器 `GET_FLAT_FILE_SALES_TAX_DATA` 采用"定时检索已生成报告"模式，而不是主动申请；若检索不到，页面提示"需在卖家后台税务文档库先生成报告"，不伪造数据；
- 订单接口的税务数据（`TAX`）作为订单级补充，二者在财务页分开标注来源；
- **前置条件**：该受限角色需在开发者应用中单独申请并经亚马逊审核。你确认过"品牌卖家具备全部权限"，这里仍需在 P1 做一次真实授权核对，若未批，销售税页显示"未授权：需申请受限角色"，不降级为假数据。

来源：税务报告类型页、报告角色对应表、`getReports` 参考页、获取税务信息指南。

## 6. 汇率主源

**事实**：
- 人民币对美元中间价由中国外汇交易中心每日 9:15 公布，也在国家外汇管理局页面公开展示。当日（2026-10-21）为 100 美元折合 671.92 元，即 6.7192；
- 中国外汇交易中心官方程序化接口（CMDS）仅面向银行间外汇市场会员，需签协议开通，实时接口按月收费；
- 该站点声明：未经书面授权，不得以电子抓取等方式获取站内内容。所以**我们不抓取其页面**；
- 公共汇率服务 Frankfurter：免费、无需密钥、无配额（仅防滥用限速）；混合汇率可免费商用，也鼓励本地存储；"单一供应商"通道仍受该供应商条款约束。
- **实测**（本机请求，2026-10-21）：
  - 混合汇率 USD→CNY = 6.6753；
  - 供应商"中国外汇交易中心"通道 USD→CNY = 6.7192，与国家外汇管理局公布值一致；
  - 供应商列表中该通道的条款链接指向上述站点声明。

**两个来源的差异**：混合汇率与官方中间价相差约 0.65%。财务口径选哪个，会直接改变人民币折算的利润。

**需要你决策（D-01）**：

| 选项 | 说明 | 风险 |
| --- | --- | --- |
| A（建议） | 主源用 Frankfurter 混合汇率（条款明确可商用与缓存）；官方中间价作为"参考值"用于对照展示，不进入利润计算 | 与官方中间价有小幅差异；页面标注来源与日期 |
| B | 主源用 Frankfurter 的"中国外汇交易中心"通道，利润口径与官方中间价一致 | 该通道受中国外汇交易中心条款约束，条款对"转发获取"的授权不明确，商业使用存在版权争议风险 |
| C | 取得中国外汇交易中心书面授权或开通会员接口 | 成本与周期不可控 |
| D | 财务人员每日手工录入官方中间价，自动源仅做提示 | 违背"每日自动接入"的已确认决策 |

在你决策前，P1 按 A 实现，数据表保留"来源"字段，切换来源不需要改结构。汇率始终以美元为基准、每日自动更新、保存每日快照并写入口径版本。
