## 阅读顺序建议

1. 先读 01 和 02：确认范围、原则和接口基线。
2. 再读 03：所有板块共用的规范与先进能力框架，后续各板块不再重复。
3. 按业务关注读 04 至 09 的板块详设。
4. 工程评审读 10 和 11。

## 术语约定

- 只用中文解释业务与设计；接口名称、报告类型、推送类型、字段名、文件名、路由路径属于代码标识，保留原文。
- ASIN、SKU、FNSKU 为亚马逊商品编码，保留原文。
- "写入开关"指页面上可切换的接口写入开关（见 03 与 09）。
- "官方数据"指亚马逊接口、报告、推送直接返回的数据；"我方计算"指本系统基于官方数据计算的结果；"模型估算"指预测、归因、模拟类结果，界面必须标注。
