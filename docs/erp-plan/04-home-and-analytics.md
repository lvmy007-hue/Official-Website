# 04 板块详设：首页与运营分析

> 每个页面默认具备 03 章的全局规范与 12 项先进能力，本章只写各页面特有的内容。"官方"指亚马逊接口、报告或推送；"我方计算"与"模型估算"按 README 术语约定标注。

## 4.1 经营控制台 `/app/overview`

**定位**：企业每天打开的第一页，回答"今天经营好不好、问题在哪、先处理什么"。

**对标与超越**：头部 ERP 提供销售看板、排行榜、利润卡片。本页在此之上增加：增长归因瀑布、断货损失估算、官方净收益对照、现金视角、数据完整度、按角色的视图模板。

**页面结构**

1. **顶部条**：全局范围、对比期（上一期、去年同期、自定义）、数据完整度（各数据域按时同步的比例）、同步健康灯、刷新、生成经营日报（日报、周报、月报模板，走导出任务）、视图模板切换（经营者、运营、财务、供应链，可在此基础上个人调整卡片布局）。
2. **第一行 7 个指标卡**：销售额、净利润、利润率、广告花费、广告占总销售比、可售天数风险数、待处理异常数。每张卡包含：数值、对比期变化、目标达成进度条、迷你趋势、可追溯入口。净利润卡右上角显示"官方净收益对照"角标，点击查看与单品经济数据的差异。
3. **第二行左：销售与利润双轴趋势**。可切换日、周、月；叠加同比与环比线；事件标注开关；主指标可切换（销售额、订单数、件数、净利润、广告花费）。点击任意一天，弹出当日指标树归因：销售额变化拆为会话、转化率、件单价三项的贡献，利润变化按利润桥拆分。
4. **第二行右：待我处理队列**。来源包括库存风险、入仓差异、结算对账、广告异常、刊登问题、同步失败、账户健康、授权即将失效、赔付机会。每条显示严重度、对象、影响金额区间、截止时间、负责人；可指派、确认、忽略（必须填写原因）、进入详情。顶部按严重度分组计数。
5. **第三行**：
   - 店铺经营对比：表格加条形图，列为销售额、净利润、利润率、广告占总销售比、库存风险数、账户健康状态；
   - ASIN 利润前后排名：前 10 与后 10，可按净利润、利润率、利润变化切换；
   - 广告异常：高花费无成交、平均超预算时长、广告成本销售比突增；
   - 库存风险分布：断货风险、冗余、库龄附加费风险、低库存水平费风险，用堆叠条展示。
6. **第四行**：
   - 增长归因瀑布：本期相对对比期的销售额变化，按店铺、贡献最大的 ASIN、新品、断货损失（模型估算：断货天数 × 断货前日均销量）逐项拆解；
   - 现金视角：本期已释放回款、递延中金额、下次预计打款日（来自财务接口交易状态与余额）。
7. **底部：数据源健康表**。行为订单、库存、财务交易、报告、数据中心、广告、营销数据流、品牌分析、消息推送；列为最近成功时间、延迟、覆盖店铺数、失败码、重试按钮。

**交互**：每张卡、每一行都能下钻到对应对象页；支持全屏大屏模式；页面上不出现任何写死的数字。

**动作**

| 动作 | 权限 | 写入开关 | 审计 |
|---|---|---|---|
| 生成经营日报 | `export.create` | 不涉及 | 是 |
| 待办指派、确认、忽略 | `workitem.assign`、`workitem.handle` | 不涉及 | 是 |
| 重试同步 | `sync.manage` | 不涉及 | 是 |

**数据来源**：经营日汇总表、利润日表、单品经济数据（`analytics_economics_2024_03_15`）、预警与待办、数据新鲜度、财务接口交易状态与余额（`listTransactions`、`listBalances`）。

## 4.2 今日实时 `/app/today`

**定位**：当天按小时监控经营。头部 ERP 大多只有隔日数据，本页基于亚马逊官方小时级推送实现。

**页面结构**

1. **今日累计**：销售件数与销售额（小时推送估算），对比昨日同时段、上周同日同时段，并显示"截至某时某分"。
2. **小时曲线**：销售、详情页流量按小时柱线；叠加历史同时段区间带（过去 4 个同星期几的低值到高值）。
3. **库存实时**：可售数量变化；断货中与预计今日断货的 ASIN 列表（按小时销售节奏外推，标注估算）。
4. **今日广告**：花费与预算消耗进度、预计超预算时间（按历史分时节奏外推，标注估算）、花费最高的活动（来自营销数据流第二版）。
5. **事件流**：报价变化、失去推荐报价资格、刊登问题新增、详情页内容被修改、新订单与取消、账户状态变化，按时间倒序。
6. **小时级异常**：销售或流量低于历史同时段区间下限时标红，可一键生成待办。

**状态**

- 页面统一标注"实时估算，以日终数据为准；推送最长可能延迟 24 小时补发"。
- 推送接收端未就绪（属部署专项）时，显示"实时数据未接入"正式状态，说明需要的配置，同时退化展示最近一次日终数据。

**数据来源**：`ITEM_SALES_EVENT_CHANGE`、`DETAIL_PAGE_TRAFFIC_EVENT`、`ITEM_INVENTORY_EVENT_CHANGE`、`ANY_OFFER_CHANGED`、`PRICING_HEALTH`、`LISTINGS_ITEM_ISSUES_CHANGE`、`BRANDED_ITEM_CONTENT_CHANGE`、`ORDER_CHANGE`、`ACCOUNT_STATUS_CHANGED`、营销数据流 `ads-performance-v1`。

## 4.3 我的待办 `/app/my/work-items`

**页签**：待我处理、我指派的、我关注的、已完成、已忽略。

**列表**：可按来源、严重度、截止时间分组。每条显示来源、对象（悬停显示对象卡片）、影响金额区间、建议动作、截止、状态、负责人、剩余时限。

**详情**（抽屉快速查看，可打开完整页）：
- 触发规则与证据（图表加关联记录）；
- 处理时间线；
- 评论与 @成员；
- 关联对象；
- 操作：转派、延期（需原因）、关闭（需填写结论：已处理、无需处理、误报）。

**批量操作**：指派、确认、忽略（需原因）。

**先进能力**：
- 时限计时，超时自动升级给上级；
- 关闭结论回流到规则质量统计（误报率、平均处理时长），用于优化预警阈值。

## 4.4 目标与预算 `/app/targets`

**内容**：按店铺 × 月份设置目标，可细化到 ASIN 组。目标项包括销售额、净利润、利润率、广告预算、目标广告成本销售比、目标广告占总销售比、目标可售天数、目标库存周转。

**页面结构**

1. **目标网格**：可编辑表格，带版本号，多人同时编辑时检测冲突。
2. **达成进度**：实际对目标；节奏线可选"按天均摊"或"按历史季节曲线分摊"，后者更贴近真实节奏。
3. **预测达成**：基于销量预测区间判断本月能否达成，给出缺口金额。
4. **变更历史**：谁在何时改了什么。

**消费方**：经营控制台、广告预算节奏、补货目标天数、利润分析。

**动作**：编辑目标（`targets.write`，写审计）。

## 4.5 业务报告 `/app/analytics/business-reports`

**定位**：店铺销量与流量的正式入口。

**顶部**：范围、日期、对比周期、指标口径、数据更新时间、数据来源（数据中心为主，报告为补充）。

**6 个页签**：销售仪表盘、按日期、销售与流量、详情页销售与流量、父体详情页销售与流量、月度销售与订单。

**指标**：订购商品销售额、订购件数、订单商品数、会话数（浏览器与移动应用分开）、页面浏览量（同样分开）、单位会话转化率、平均售价、购物车获得率、退款件数与退款率。

**组件**：
- 指标卡；
- 趋势图：多指标叠加，可切换左右轴；
- 转化漏斗：会话 → 页面浏览 → 订单商品 → 件数；
- 明细表（AG Grid），可下钻到 ASIN 360。

**先进能力**：
- 指标树归因：销售额变化拆为会话、转化率、件单价三项的贡献；
- 移动端与桌面端拆分对比；
- 对比期并排列；
- 与广告数据联动，拆分自然销售与广告销售。

**数据来源**：`analytics_salesAndTraffic_2024_04_24` 的 `salesAndTrafficByDate`、`salesAndTrafficByAsin`、`salesAndTrafficTrends`；补充 `GET_SALES_AND_TRAFFIC_REPORT`。

## 4.6 ASIN 与父体分析 `/app/analytics/asins`

**列表页**

- **左侧**：父体树（父体 → 子体），可按品牌、类目、标签、负责人、库存风险、刊登问题筛选。
- **主区**：所选对象的趋势，指标为销售额、会话、浏览量、转化率、价格、购物车获得率、广告销售、自然销售（总销售减广告销售）、退货率、可售天数、销售排名。
- **对比模式**：最多 5 个 ASIN 并排。
- 点击 ASIN 进入 ASIN 360（见 05 章）。

**父体详情** `/app/analytics/parents/:parentAsin`

- **身份区**：父体编号、子体数、总销售额、净利润、转化率、有库存风险的子体数。
- **页签**：
  1. 子体贡献矩阵：
     - 热力图，行为子体，列为指标，颜色可切换为销售额、转化率或库存风险；
     - 可按变体属性透视，例如"颜色 × 尺码"矩阵，一眼看出哪个组合卖得好、哪个缺货。
  2. 子体趋势：多子体叠加。
  3. 流量分布：会话在各子体间的占比及变化。
  4. 库存与补货：各子体可售天数、补货建议。
  5. 广告覆盖：哪些子体有广告、花费与销售，标出覆盖缺口。
  6. 评论主题：父体级正面与负面主题。
  7. 变体结构变更历史：增删子体、属性变化。

**数据来源**：数据中心销售与流量（父体、子体粒度）、商品目录父子关系、广告商品报表、库存、客户反馈。

## 4.7 品牌分析 `/app/analytics/brand/...`

### 搜索查询表现 `search-query`

- **维度**：按 ASIN 或按品牌；按周、月、季。
- **关键词漏斗**：展示、点击、加购、购买四层，每层显示市场总量、我方数量、我方份额。
- **搜索量与份额趋势**。
- **价格对比**：我方点击、加购、购买的中位价，对比市场中位价。
- **配送速度对比**：当日、次日、两日送达的份额。
- **词表**：搜索量、我方展示份额、点击份额、加购份额、购买份额、份额变化、是否已投放广告。可跳转"加入投放"，该动作受写入开关控制。

**先进能力**：
- **机会象限**：以搜索量为横轴、购买份额为纵轴。
- **份额漏斗断点诊断**：
  - 展示份额高但点击份额低：提示检查主图、标题、价格；
  - 点击高但加购低：提示检查详情页与评论；
  - 加购高但购买低：提示检查价格与配送速度。
- **品牌搜索份额总览**：按核心词组汇总我方占有率，以官方份额数据替代抓取式的搜索份额工具。

### 目录表现 `catalog-performance`

- ASIN 维度的曝光、点击、加购、购买漏斗；
- 搜索带来的流量与全部流量对比；
- 可联动到刊登表现、广告、库存。

### 热门搜索词 `search-terms`

- 搜索频率排名的趋势；
- 每个词点击前三的 ASIN，以及它们的点击份额与转化份额；
- 我方是否进入前三；
- 竞品 ASIN 可一键加入竞品监控；
- 词可分组为机会词与风险词。

### 购物篮分析 `market-basket`

- 与我方 ASIN 同篮购买的商品组合与同篮率；
- 关联 ASIN 热力矩阵；
- 可用于捆绑销售与广告商品定向的建议。

### 重复购买 `repeat-purchase`

- 订单数、独立买家数、复购订单占比、复购销售额占比；
- 可按品牌、ASIN 拆分，看趋势。

**数据来源**：品牌分析 5 类报告（见 02 章 2.3）。

## 4.8 促销与优惠券 `/app/promotions`

**列表**

| 列 | 来源 |
|---|---|
| 类型（秒杀、优惠券、价格折扣、满减）、名称、状态、开始与结束时间、商品数、校验问题 | `Promotions API v2025-12-01` |
| 预算、已兑换次数 | 促销接口与优惠券表现报告 |
| 平台费用（秒杀费、优惠券兑换费） | 费用事件 |
| 带来的销量与销售额 | `GET_PROMOTION_PERFORMANCE_REPORT`、`GET_COUPON_PERFORMANCE_REPORT`（通过映射编号关联） |

**详情** `/app/promotions/:id`

- **身份区**：类型、状态、时间、折扣力度、商品数、校验问题数。
- **页签**：
  1. 效果：活动期间的销量与销售额，对比活动前同期基线（前后对照）。
  2. 商品明细：每个商品的折扣、销量、销售额、毛利变化。
  3. 成本：折扣成本 + 平台费用。
  4. 利润影响：活动期利润与基线利润对比。
  5. 校验问题：接口返回的问题与处理建议。
  6. 关联广告：活动期间相关商品的广告表现。

**先进能力**：促销真实回报 = 增量毛利 ÷（折扣成本 + 平台费用）。增量部分为模型估算（基线法），界面标注方法。

**动作**：若促销接口支持修改，则受写入开关控制；否则只读，并提示到卖家后台操作。

## 4.9 订阅省 `/app/subscribe-save`

**指标**（`Replenishment API v2022-11-07` 的卖家指标）：活跃订阅数、订阅出货件数、订阅销售额、取消数、未来 30、60、90 天预计订阅出货件数、参与订阅省的报价。

**页面**：
- 指标卡与趋势；
- ASIN 级明细表；
- 报价参与列表。

**先进能力**：预计订阅出货件数作为确定性需求，纳入销量预测与补货计算（见 06 章）。
