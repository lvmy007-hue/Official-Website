# 15 设计系统与交互规范

- 版本：第 1 版（CR-096 入档，2026-10-25 确认）
- 适用范围：ERP 工作区全部页面（`/app/*`），从阶段 6 起生效。官网不受影响，官网零改动仍是硬规则。
- 地位：阶段 6 所有界面工作的唯一依据。和 03 章 3.2、3.3 冲突时，以 03 章为准，并走 14.7 变更流程修正本章。

## 1. 总原则

1. **商业化、大厂风格**：对标国内一线企业级后台的通行做法：中性灰为底、单一主色、克制用色、信息密度高、排版整齐。界面要让人觉得"是一个成熟的企业产品"，而不是"一个 AI 生成的演示页"。第 2 节列出硬性禁止项。
2. **高密度、可扫读**：一屏尽量多放有用的数据，但每个数字都要能说清楚口径、来源和更新时间。
3. **少数骨架反复套用**：全站只用 5 种页面骨架（第 5 节）。新页面先选骨架再填内容，不新造布局。
4. **口径随处可查**：凡是指标，列头或卡片标题旁都有问号，内容统一取自指标口径字典，页面里不手写口径。
5. **不做假东西**：没有接口支撑的按钮不显示；没有数据就显示原因和处理入口，不放示例数据。
6. **写操作留痕**：先确认、再执行、执行后写审计；审计记录能在相关对象的趋势图上打点显示。

## 2. 大厂风格基线与禁止项

### 2.1 基线

| 方面 | 要求 |
|---|---|
| 用色 | 只有一个主色（第 3 节 `brand`）。绿、橙、红只表达状态和涨跌，不做装饰。大面积区域只用白色和中性灰 |
| 层次 | 靠留白、1px 描边、字重和字号区分层次；卡片不加阴影，只有浮层（下拉、抽屉、弹窗、提示）才有阴影 |
| 形状 | 控件圆角 4px，卡片和抽屉 6px，标签 2px。不做胶囊形按钮，不做大圆角卡片 |
| 字体 | 系统字体，正文 13px，字重只用 400、500、600 三档 |
| 图标 | 全站一套线性图标（Ant Design Icons），尺寸 14 或 16px，颜色跟随文字 |
| 动效 | 只用于状态反馈（展开、出现、加载），时长 150 到 250ms，不做装饰性动画 |
| 图表 | 主色加 2 到 3 个辅助色；面积填充透明度不超过 0.12；柱子实色，圆角不超过 2px |

### 2.2 禁止项（出现任何一条即为不合格）

1. 渐变背景、渐变按钮、渐变文字、渐变边框（骨架屏的加载闪光除外）。
2. 紫色、粉色、霓虹色、高饱和撞色作为界面装饰色。
3. 带主色的发光阴影、卡片阴影、悬停上浮、毛玻璃（`backdrop-filter`）。
4. 每张指标卡一种颜色、彩色底卡片、彩色分组图标块。
5. 在界面里使用表情符号（如"✨""📁""🔍""🏢"）代替图标。
6. "AI""智能""✨"之类的营销式标签和装饰文案。
7. 超过 8px 的圆角、全站胶囊形控件。
8. 装饰性插画、大号空状态插图、居中的落地页式布局。
9. 同一视图中出现两套以上的强调色，或同一区域里出现两个以上主按钮。
10. 组件里直接写色值、阴影或像素魔数（只能引用第 3 节的令牌）。

### 2.3 自动检查

P6-01 增加一项样式守卫测试，扫描 `src/erp/**`（`.ts`、`.tsx`、`.css`）：

- 出现 `linear-gradient`、`radial-gradient`、`backdrop-filter` 时失败（白名单只有骨架屏组件）；
- 出现令牌文件以外的十六进制色值时失败（白名单只有 `theme/` 目录）；
- 界面文案里出现表情符号时失败（扫描 JSX 文本节点和中文文案常量）。

守卫测试本身要有"故意违规就失败"的反向用例。

## 4. 排版与协调性

### 4.1 页面结构（自上而下，间距固定）

| 区域 | 规则 |
|---|---|
| 面包屑 | 12px，`inkMute`，距内容区顶部 12px |
| 标题行 | 标题 18px/600；右侧最多 1 个主按钮加 2 个次按钮，其余收进"更多"；数据新鲜度放在标题下方单独一行 |
| 状态页签 | 下划线页签，带计数；和标题行间距 12px |
| 筛选栏 | 白底卡片，1440px 宽度下必须一行放下（第 7 节）；和下方间距 12px |
| 已生效条件 | 标签行，紧贴筛选栏；没有条件时不占位 |
| 指标卡区 | 4 到 7 张等宽卡片，间距 12px；和下方间距 12px |
| 图表区 / 表格区 | 卡片间距 12px；左右两栏布局时两栏顶部和底部对齐 |

内容区左右边距 20px；页面最小宽度 1120px；低于此宽度出现横向滚动，不做响应式折叠。

### 4.2 对齐

1. 同一行的控件高度一致：常规 30px，表格工具栏和卡片头里的小按钮 24px。
2. 文字左对齐，数字右对齐并使用等宽数字（`font-variant-numeric: tabular-nums`）；表头的对齐方式和该列数据一致。
3. 卡片头高度统一（44px），标题 14px/600，右侧依次放局部切换、操作链接。
4. 表单标签宽度在同一表单内统一，标签右侧对齐控件。
5. 任何一行都不允许只折出一个孤立的按钮或标签；放不下时减少常驻项，收进"更多"。

### 4.3 信息密度

- 宽表默认紧凑行高 36px；个人设置可切到标准 40px。
- 长文本单行截断，悬停显示全文；编码类（ASIN、SKU、单号）点击可复制。
- 一个页面同时出现的强调色（主色以外）不超过 2 种。

## 5. 五种页面骨架

### 5.1 列表页（最常用）

自上而下：标题行 → 状态页签 → 筛选栏 → 已生效条件 → 汇总指标卡（可选）→ 数据表格 → 行详情（抽屉或整页）。

### 5.2 分析宽表页（商品表现、利润报表、广告各层级）

在列表页的基础上增加：维度切换（分段控件，放在筛选栏上方，右侧是视图选择）、列分组和列模板、可折叠的趋势区（多指标叠加，本期和上期对比）。

### 5.3 整页详情（ASIN 360、库存详情、订单详情、货件详情）

- **头部信息卡**：主图、标题、状态标签、编码字段组（"字段名 值"排成一行，可换行）、4 到 7 个关键指标（用竖线分隔，不做小卡片）、主操作。滚动时收缩成一行吸顶。
- **吸顶导航**：板块少用页签，板块多用锚点（ASIN 360 用锚点）。都用下划线样式。
- **共享筛选**：日期范围和对比方式放在吸顶导航同一行右侧，全页共用。
- **右侧关联栏**：保留现有设计，可以折叠。
- 每个板块一张卡片，局部切换放在卡片头右侧。

### 5.4 流程页（入仓计划、关账、导入）

- 顶部步骤条，每一步显示未开始、进行中、已完成、出错。
- 下一步、上一步、作废等按钮能不能点，由服务端返回的按钮状态决定，前端不自己判断。
- 不可逆的步骤执行前必须二次确认，说明后果和作废时限。
- 每一步都能保存草稿。

### 5.5 配置页（预警规则、调价规则、自动规则、业务配置）

- 规则列表：名称、对象、条件摘要、状态开关、最近触发、创建人、操作。
- 规则编辑：左边表单，右边"规则描述"（根据配置实时生成一句话）。
- 条件构造器：一条条件由"指标、统计窗口、对比窗口、比较符、百分比或绝对值、阈值"组成；组内"且"，组间"或"。
- 模板：新建时可以引用模板，系统模板和自定义模板分开显示。
- 业务配置卡片：配置名、当前值、影响范围、编辑入口。

## 6. 数据表格规范

在现有 `MassiveGrid` 的基础上补齐：

| 能力 | 要求 |
|---|---|
| 分页 | 无限滚动（游标）和页码分页两种模式，由页面选择 |
| 列配置 | 显示、顺序、列宽、固定列；存服务端，可共享给团队 |
| 列分组 | 两层表头，例如"销售 / 流量 / 广告 / 利润 / 库存 / 售后" |
| 视图 | 列、筛选、排序、维度；"系统默认、我的、团队共享"三级 |
| 固定列 | 左侧固定商品信息列，右侧固定操作列，固定边缘有细阴影分隔 |
| 汇总行 | 表头下方固定一行，取服务端汇总接口，不在前端求和 |
| 列头问号 | 所有指标列头都有问号，内容来自口径字典 |
| 异步列 | 慢的列单独请求，先显示占位，返回后淡入 |
| 单元格类型 | 商品（图、标题、ASIN、SKU、站点）、金额、百分比、涨跌、双行（本期 / 上期加涨跌）、状态标签、迷你趋势、进度条、人员、时间（悬停显示站点时区）、估算值（带"估"角标） |
| 行内展开 | 父 ASIN 展开子体、装箱展开箱内明细 |
| 批量操作 | 勾选后在表格底部出现白底操作条（不用深色或主色底） |
| 视觉 | 表头 `#f7f8fa` 底，行分隔用 `lineSoft`，不画竖线（列分组表头除外）；悬停行 `#f7f8fa`；选中行 `brandSoft` |

## 7. 筛选栏规范

- **常驻区**：日期快捷项（今天、近 7 天、近 30 天、本月、自定义）、对比方式、3 到 4 个最常用的下拉、搜索框（可切换按什么搜，支持批量粘贴）。
- **右侧固定**："更多筛选"（按钮上显示已生效条件数）和"重置"。
- **筛选方案**：与视图共用存储；入口放在视图选择里，不在筛选栏里重复。
- **日期组件**：完整快捷项（今天、昨天、近 7/14/30 天、本月、上月、本季、本年、自定义）放在日期下拉里；对比方式可选环比、同比、自定义；按站点时间计算。
- **已生效条件**：标签形式，可以逐个删除，也可以一键重置。
- 1440px 宽度下必须一行放下；放不下时减少常驻下拉，收进"更多筛选"。

## 8. 详情的三种形态

| 形态 | 什么时候用 | 规范 |
|---|---|---|
| 抽屉 | 快速查看、轻量编辑、不离开列表 | 宽度 720px 或 960px，直角贴右边；顶部对象标识和主操作，下面用页签；有"在新页签打开完整详情" |
| 弹窗下钻 | 层级对象，例如广告活动下的广告组、投放、搜索词 | 宽度 920px 到屏宽 90%，居中；内部仍是列表骨架，可以继续下钻，顶部面包屑 |
| 整页详情 | 核心对象：商品、库存、订单、货件、结算 | 见 5.3 |

## 9. 图表规范

- 统一用 ECharts（`ErpChart`、`ChartPanel`），按需加载，不进首屏。
- 趋势图：多指标、左右双轴；粒度时、日、周、月；本期和上期叠加；悬停时显示同一时刻全部指标（白底提示框）。
- 事件打点：趋势图下方一条事件带，按类型着色（运营日志、价格、广告变更、预警、Listing 变更），可以开关；点圆点看详情；同一天多个事件合并显示数量。
- 占比图：环形图或横向条形图，图例可点击隐藏。
- 图表和表格联动：点图表上的日期或系列，同页表格筛选到对应数据。
- 每张图右上角提供"切换为表格"和"下载图片"。
- 图例用短线加文字，不用胶囊底色。

## 10. 动态与反馈

| 场景 | 规范 |
|---|---|
| 首次加载 | 骨架屏，形状和最终内容一致，不用整页转圈 |
| 局部刷新 | 只在刷新区域显示细进度条，旧数据保留到新数据返回 |
| 异步列和慢指标 | 单元格里显示占位，返回后淡入 |
| 长任务（导出、同步、批量计算） | 右下角任务浮层显示进度，完成后通知 |
| 抽屉、弹窗 | 200ms 滑入或淡入，尊重系统的"减少动画"设置 |
| 页面切换 | 内容区淡入 150ms，不做位移动画 |
| 数字变化 | 短暂底色高亮，不做滚动计数动画 |
| 操作结果 | 成功用轻提示（白底、绿色图标）；失败用常驻提示并说明原因和处理办法；批量操作结束后显示"成功 N 条、失败 N 条" |
| 实时数据 | 今日实时、今日广告每 5 分钟自动刷新，显示"N 分钟前更新"；页面不在前台时暂停 |
| 未读数轮询 | 顶栏消息和预警未读数每 60 秒轮询一次，页面不在前台时暂停 |
| 空状态和错误状态 | 沿用 `DataState`：说明原因、数据域、处理入口；不用插画 |

## 11. 外壳

- **顶栏**（高 56px，白底，底部 1px 描边）：左侧 Logo 和企业切换、全局范围（店铺、站点、币种，白底描边下拉）；中间全局搜索（沿用 `CommandPalette`）；右侧写入模式标识、待办、消息与预警（带未读数）、导出中心、头像。
- **侧边导航**（宽 216px，可收起成图标栏）：两级菜单，一级为业务域（灰色线性图标），二级为页面；选中项用 `brandSoft` 底加主色文字；顶部有"收藏"分组。
- **多页签**（高 40px，白底）：打开的页面形成页签，选中页签用 `brandSoft` 底；可关闭、右键"关闭其他"；最多 15 个，超出关闭最久未用的。
- **消息与预警浮层**：下划线页签"消息 / 预警"，各带未读数；底部"全部""全部标为已读""通知设置"。

## 12. 权限在界面上的表现

- 没有页面权限：导航不显示；直接访问时显示所需权限点。
- 没有按钮权限：隐藏，或置灰并在悬停时说明原因，由权限配置决定。
- 敏感字段（采购成本、货值、供应商、买家信息）：没有权限时显示 `***` 和锁图标；查看买家明文需要单独授权，每次查看写审计。

## 13. 性能预算

- 首屏脚本预算 350KB（2026-10-25 确认，原为 300KB）。外壳只包含顶栏、导航、页签条和路由。
- AG Grid、ECharts、条件构造器、拖拽画布等大组件按路由或按需加载。
- 宽表只请求可见列的数据。
- 放宽到 350KB 后仍然放不下时，STATUS 改为 BLOCKED，请人决定。

### 14.2 每个界面工作包的自检清单

界面工作包交付前逐条自检，结果写进 CR：

1. 页面属于第 5 节五种骨架中的哪一种，结构顺序与 4.1 一致。
2. 第 2.2 节十条禁止项逐条确认没有出现；样式守卫测试通过。
3. 只引用令牌，没有新的色值和像素魔数。
4. 1440px 宽度下筛选栏一行放下，没有孤立折行；同一行控件高度一致；数字列右对齐。
5. 指标列头有问号，内容来自字典。
6. 加载、空、错误三种状态齐全。
7. 有浏览器环境时附 1440px 宽的截图，并与原型对应页面比对；没有浏览器环境时写明"未走查"。
