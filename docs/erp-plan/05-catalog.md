# 05 板块详设：商品

---

## 5.1 商品主数据 `/app/products`

**列表字段**：图片、ASIN、卖家 SKU、FNSKU、父体、品牌、类目、履约方式、刊登状态、价格、可售、近 30 天销售、刊登问题数、刊登质量分、近 30 天利润率、负责人、标签、更新时间。

**筛选**：ASIN、SKU、父体、品牌、类目、状态、是否有刊登问题、库存风险、负责人、标签、刊登质量分区间。

**批量动作**（只放真实可执行的）：
- 同步；
- 导出；
- 创建补货草稿；
- 设置负责人与标签（系统内数据，不写亚马逊）；
- 加入关注；
- 进入详情。

不做"批量修改刊登"。修改刊登在"刊登质量与合规"中按问题逐条处理，或走批量任务，并经过写入开关与校验预览。

## 5.2 ASIN 360 `/app/products/:id`

**定位**：一个商品的全部经营信息集中在一页，运营分析与商品两处入口共用。这是全系统最核心的详情页。

**对标与超越**：头部 ERP 的产品表现页已整合销量、库存、流量、广告、利润与运营日志。本页增加：
- 单品经济瀑布及官方对照；
- 价格模拟与预期获胜价对照；
- 份额漏斗诊断；
- 评论主题与类目头部商品对比；
- 他人修改详情页告警；
- 历史内容字段级对比；
- 每个操作的前后对照。

### 身份区

- 主图（可切换全部图片）、ASIN、卖家 SKU（多个 SKU 时可切换）、FNSKU、标题、父体链接、品牌、类目路径；
- 状态标签：刊登状态、可售状态、是否被搜索抑制；
- 价格组：我方价格、当前推荐报价价格、获得推荐报价的预期价格；
- 推荐报价归属：是否为我方，会员与非会员分段的浏览权重；
- 销售排名：主类目与子类目；
- 评分与评分数（标注来源）；
- 可售数量与可售天数；
- 同步状态、负责人、标签、关注按钮。

**关键指标卡**：近 30 天销售额、净利润、利润率、转化率、广告占总销售比、可售天数，均带对比期变化。

### 建议动作区（示例规则）

| 触发条件 | 建议 | 预估影响 | 执行入口 |
|---|---|---|---|
| 我方价格高于预期获胜价 | 调整至预期获胜价 | 模拟利润变化与推荐报价获得率变化 | 价格模拟器 → 修改价格（受写入开关） |
| 可售天数低于目标 | 生成补货建议 | 断货损失区间 | 补货建议 |
| 新增刊登错误 | 修复刊登 | 是否影响可售 | 刊登质量与合规 |
| 负面评论主题占比上升 | 查看主题与关联退货原因 | 退货率变化 | 评价页签 |
| 库龄附加费即将收取 | 移除或促销 | 预计费用 | 库存详情 |
| 详情页内容被他人修改 | 核对差异 | — | 内容页签 |

### 12 个页签

1. **经营表现**
   - 销售额、件数、订单趋势，带事件标注；
   - 利润趋势；
   - 本期对比期的指标树归因；
   - 同比、环比表；
   - 自然销售与广告销售的拆分；
   - 退款趋势。
2. **流量转化**
   - 会话（移动端、桌面端）、浏览量、转化率、购物车获得率的趋势；
   - 本 ASIN 在搜索查询表现中的核心词份额漏斗及断点诊断；
   - 目录表现漏斗；
   - 近 14 天小时级流量（推送接入后）。
3. **广告**
   - 关联的广告活动、广告组、投放对象、搜索词；
   - 花费、销售额、广告成本销售比、广告占总销售比的趋势；
   - 光环销售（来自营销数据流 `ads-converted-product-v1`）；
   - 品牌分析中份额高但尚未投放的搜索词清单。
4. **库存补货**
   - 库存结构趋势：可售、预留（订单预留、中转、仓内处理）、在途（处理中、已发货、接收中）、不可售、调查中；
   - 可售天数与目标对比；
   - 补货建议：我方建议与亚马逊官方补货建议并列，并显示差异原因；
   - 在途货件与预计到仓时间；
   - 上游仓储库存；
   - 低库存水平费与库龄附加费风险。
5. **利润与成本**
   - 单位经济瀑布：售价 → 佣金 → 配送费 → 仓储分摊 → 广告分摊 → 退款损失 → 采购成本 → 头程 → 关税 → 净利；
   - 我方计算与官方单品经济的对照；
   - 成本版本时间线；
   - 费用预览：未来 120 天的费用变化及其影响（`economicsPreview`）；
   - 价格模拟器：输入目标价，显示净利、是否达到预期获胜价、单品经济模拟结果（`economicsSimulation`）。
6. **退货**
   - 退货率趋势、退货原因分布、处置状态；
   - 本 ASIN 所在类目的退货主题（客户反馈接口）；
   - 关联赔付。
7. **刊登与问题**
   - 刊登状态、问题清单（严重度、涉及属性、修复建议）、刊登限制、搜索抑制状态；
   - 刊登质量分（我方计算：必填与推荐属性完整度、图片数、五点描述条数、A+ 状态、问题数）；
   - 属性完整度与商品类型定义的对照。
8. **评价**
   - 评分与评分数（标注来源）；
   - 前 10 正面与前 10 负面评论主题及占比；
   - 与类目全部商品、类目前 25% 商品的对比；
   - 主题趋势；
   - 请求评价覆盖率。
9. **定价与购物车**
   - 价格历史：我方价格、推荐报价价格、最低价；
   - 获得推荐报价的预期价格；
   - 竞争报价列表：卖家、配送方式、价格、会员资格；
   - 推荐报价获得率；
   - 失去推荐报价事件、价格健康事件。
10. **竞品**
    - 关注竞品的价格、销售排名、推荐报价状态；
    - 趋势对比；
    - 热门搜索词前三中的点击份额对比。
11. **内容与 A+**
    - 当前详情页内容：标题、五点描述、描述、图片、A+；
    - 任选两个日期做字段级对比；
    - 他人修改告警（品牌商品内容变更推送）。
12. **变更与审计**
    - 运营日志时间线：系统内操作、亚马逊侧变更、手工记录；
    - 每条可展开查看前后对照。

### 动作

| 动作 | 权限 | 写入开关 | 前置条件 | 审计 |
|---|---|---|---|---|
| 修改价格 | `pricing.price.write` | 卖家接口·修改价格 | 先经刊登接口的价格校验预览 | 是 |
| 修复刊登 | `listing.write` | 卖家接口·修改刊登 | 先经刊登接口的校验预览模式 | 是 |
| 生成补货建议 | `replenishment.plan.create` | 不涉及 | — | 是 |
| 设置负责人、标签、关注 | `catalog.meta.write` | 不涉及 | — | 是 |

### 数据来源

- 商品目录 `Catalog Items API v2022-04-01`；刊登 `Listings Items API v2021-08-01`；刊登限制；商品类型定义；
- 定价 `Product Pricing API v2022-05-01`；
- 数据中心销售与流量、单品经济；
- 亚马逊物流库存接口与库存规划报告；
- 客户反馈接口；A+ 内容接口；
- 广告新报告接口与营销数据流；
- 推送：`ANY_OFFER_CHANGED`、`PRICING_HEALTH`、`BRANDED_ITEM_CONTENT_CHANGE`、`LISTINGS_ITEM_ISSUES_CHANGE`。

## 5.3 刊登表现 `/app/listings`

**上半部分**：
- 指标趋势；
- 异常分布：转化率骤降、推荐报价丢失、刊登问题新增、被搜索抑制。

**下半部分**：可配置的海量表格，列为会话、浏览量、转化率、销量、销售额、购物车获得率、价格、评分、评分数（标注来源）、广告销售、退货率、可售天数、刊登问题数、刊登质量分、负责人。

**交互**：
- 点击行进入 ASIN 360；
- 支持保存视图与对比模式。

## 5.4 刊登质量与合规 `/app/listings/quality`

**7 个页签**：问题项、被搜索抑制、刊登限制、属性缺失、商品类型变更、他人内容修改、非活跃刊登。

**每条问题包含**：ASIN 与 SKU、问题代码、描述、严重度（错误、警告）、影响（是否导致不可售或被抑制）、首次出现时间、修复建议、负责人、状态。

**动作**：
- 修复刊登：局部修改，提交前用刊登接口的校验预览模式确认；受写入开关控制，写审计。
- 批量修复：走批量任务（`Feeds API`），处理完成后由推送回写结果。

**先进能力**：
- 问题生命周期统计：新增、处理中、已解决，平均解决时长；
- 问题对销售的影响估算：问题存续期与此前同期对比，标注估算。

**数据来源**：刊登接口问题项、`GET_MERCHANTS_LISTINGS_FYP_REPORT`、刊登限制接口、商品类型定义、推送 `LISTINGS_ITEM_ISSUES_CHANGE`、`LISTINGS_ITEM_STATUS_CHANGE`、`ITEM_PRODUCT_TYPE_CHANGE`、`BRANDED_ITEM_CONTENT_CHANGE`。

## 5.5 定价与购物车 `/app/pricing`

**列表字段**：
- SKU、ASIN；
- 我方价格、最低报价、推荐报价价格与获得方；
- 获得推荐报价的预期价格、我方价格与预期价格的差距；
- 推荐报价获得率、会员与非会员分段浏览权重；
- 价格健康状态、最近一次价格变化；
- 当前价格下的利润率、按预期获胜价计算的利润率。最后两列并排，一眼看出"调价后利润还剩多少"。

**SKU 详情** `/app/pricing/:sku`

- 价格历史曲线：我方价格、推荐报价价格、最低价；
- 竞争报价快照；
- 事件：报价变化、价格健康；
- 调价模拟器：输入价格，返回单品经济模拟利润、是否达到预期获胜价，以及基于历史数据的价格弹性估算（标注估算）；
- 调价历史及每次调价的前后对照。

**动作**：
- 修改价格：`pricing.price.write`，受写入开关控制，提交前做价格校验预览，写审计。
- 价格护栏：为每个 SKU 设置最低价、最高价。这是系统内规则，任何改价（包括批量）超出护栏时一律拦截。
- 定价规则：手动与自动两种模式并存，可按规则分别设置。
  - **手动模式**：规则命中后只生成调价建议，进入待办，由人工确认后执行。
  - **自动模式**：规则命中后直接执行，前提是写入开关页中"定价规则自动执行"已开启。自动执行同时受以下保护：
    - 价格护栏（最低价、最高价）；
    - 单次调幅上限；
    - 每个 SKU 每日执行次数上限；
    - 熔断：连续失败，或调价后转化率、利润率跌破阈值时，自动暂停该规则并告警。
  - **通用**：规则支持试运行（用历史数据模拟命中情况）；每次执行写执行记录与审计，并自动生成前后对照。

**数据来源**：`getFeaturedOfferExpectedPriceBatch`、`getCompetitiveSummary`、`Product Fees API`、数据中心单品经济模拟、推送 `ANY_OFFER_CHANGED`、`PRICING_HEALTH`。

## 5.6 竞品监控 `/app/competitors`

**竞品来源**：
- 热门搜索词前三 ASIN；
- 竞争摘要中的其他报价方；
- 手工添加。

**列表字段**：竞品 ASIN、品牌、价格、推荐报价状态、配送方式、会员资格、销售排名、在我方核心词中的点击份额、与我方的价格差、与我方的排名差。

**详情** `/app/competitors/:asin`：
- 价格与销售排名趋势；
- 目录属性变化快照，例如标题、图片数量变化；
- 在我方核心词中的点击份额趋势；
- 与我方对应 ASIN 的并排对比。

**边界**：只用官方接口与报告，不抓取亚马逊前台页面。竞品的评分没有官方来源，显示"无官方来源"。

## 5.7 评价与反馈 `/app/reviews`

**4 个页签**

1. **评分概况**：每个 ASIN 的评分、评分数（来源标注：文件导入或其他官方来源）、趋势。
2. **评论主题**：
   - ASIN 前 10 正面与前 10 负面主题，及提及占比；
   - 与类目全部商品、类目前 25% 商品对比；
   - 类目近 6 个月主题趋势。
3. **退货主题**：类目级退货主题与趋势。
4. **请求评价**：
   - 可请求订单列表：送达后第 5 至 30 天、尚未请求；
   - 批量请求：受写入开关控制，每单只请求一次，写审计；
   - 请求覆盖率；
   - 请求后评分数增长（前后对照）。

**先进能力**：把负面评论主题与退货原因交叉分析，生成产品改进清单，可指派给产品或供应链负责人跟进。

**数据来源**：`Customer Feedback API v2024-06-01`、`Solicitations API v1`、评分文件导入。

## 5.8 A+ 内容 `/app/aplus`

**列表字段**：内容名称、类型、状态（草稿、已提交、已批准、被拒、已发布）、关联 ASIN 数、最近更新、拒绝原因。

**详情** `/app/aplus/:id`：
- 按接口返回的模块结构渲染预览；
- 关联 ASIN；
- 审核状态时间线；
- 拒绝原因与修复建议；
- 发布前后的转化率对比（前后对照）。

**动作**：
- 结构化模块编辑器创建、编辑；
- 上传图片（`Uploads API`）；
- 关联 ASIN；
- 提交审核。

以上动作均受写入开关控制，写审计。

**数据来源**：`A+ Content Management API v2020-11-01`、数据中心销售与流量。

## 5.9 商品成本 `/app/costs`

**列表字段**：
- SKU；
- 当前成本版本：生效日、采购单价、币种、折合美元；
- 单位头程分摊、单位关税、其他成本、到岸成本合计；
- 成本覆盖状态、最近变更时间。

**详情**：
- 成本版本时间线；
- 每个版本的来源：采购单、头程单、手工录入、导入；
- 成本构成饼图；
- 按企业设置的计价方法（先进先出、移动加权、月末加权）计算的库存成本。

**动作**：录入、导入、版本对比，均写审计。已关账期间的成本不受后续修改影响。

**消费方**：利润分析、价格模拟器、补货资金占用估算。
