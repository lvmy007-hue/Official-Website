# 03 技术架构、全局规范与先进能力框架

## 3.1 技术架构

### 前端

| 层 | 选型 | 说明 |
|---|---|---|
| 构建 | Vite + React + TypeScript | 保留现有构建，官网不受影响 |
| 路由 | TanStack Router | 地址栏参数（范围、筛选、分页、排序）类型校验；路由级数据预加载；路由与链接类型安全；按页面懒加载；路由守卫按权限拦截 |
| 组件库 | Ant Design 5（紧凑模式） | 主题令牌对齐官网色值，中文语言包；ProComponents 按需用于高级表单与详情 |
| 海量表格 | AG Grid 社区版 | 无限滚动行模式 + 服务端游标分页；排序、筛选下推后端；分组聚合由后端汇总接口完成；导出走服务端任务 |
| 中小表格 | Ant Design 表格 | 配置类、管理类 |
| 图表 | ECharts（项目现有按需加载封装） | 统一主题、统一工具栏（下载、全屏、切换维度、事件标注开关） |
| 数据请求 | TanStack Query | 缓存、去重、重试、轮询、乐观更新（仅用于本地编辑态，不伪造服务端成功） |
| 类型与校验 | `packages/api-contracts` 共享校验定义 | 前后端同一份类型，接口变更编译期发现 |
| 图标 | Ant Design 图标 | ERP 内统一 |

### 后端

| 层 | 选型 | 说明 |
|---|---|---|
| 接口服务 | NestJS，按领域拆分模块 | 认证、租户与范围、商品目录、定价、评价、A+ 内容、订阅省、库存、亚马逊仓储分销、补货、采购、国内仓、头程、入仓、订单、售后、支持案件、财务、利润、税务、广告、运营分析、预警与待办、账户健康、报表、导出、连接、推送、同步、审计、设置、汇率、写入开关 |
| 横向拦截器 | 范围权限、审计、请求编号、错误码统一、写入开关校验 | 所有领域模块统一挂载 |
| 数据库 | PostgreSQL | 按月分区、日汇总表、连接池中间件；代码层预留读写分离 |
| 缓存与限流 | Redis 实例甲 | 短时缓存（写操作或同步完成时主动失效）、按用户与租户限流 |
| 任务队列 | Redis 实例乙 + BullMQ | 按数据域拆分队列；店铺级令牌桶限速（按亚马逊响应头动态调整）；租户公平调度；任务去重（店铺 + 数据域 + 时间窗） |
| 对象存储 | 开发：本地磁盘；生产：阿里云对象存储 | 原始报告文件、数据中心结果、营销数据流文件、导出文件、附件 |
| 密钥 | 主密钥加密数据密钥，支持轮换 | 开发用本地密钥；生产接云密钥管理服务 |

### 后台任务进程结构

```
connectors/   卖家接口、广告接口、数据中心、营销数据流客户端（含限速与重试）
importers/    每种报告、每个数据集一个解析器
derivers/     利润、销量预测、补货建议、预警评估、赔付机会识别、费用核查、自动规则、分时策略、经营日报、双源核对
listeners/    消息推送事件处理（接收端为部署专项）
```

## 3.2 全局页面规范

### 列表与工作台页

从上到下：

1. **页头**：标题、一句话说明、主动作。
2. **数据新鲜度条**：数据范围（主体、店铺、站点、时间）、时区、币种、最近成功同步时间、数据来源、数据质量提示数。
3. **业务页签**：同一模块的不同视图。
4. **筛选区**：继承全局范围，加本页筛选；显示"已应用 N 个条件"；可保存为视图（个人、团队共享）。
5. **指标卡带**：当前筛选下的汇总，带同比、环比、目标对比。
6. **图表区**：可折叠；图上可叠加事件标注。
7. **海量表格**：列配置、排序、固定列、行内迷你趋势图、勾选后出现批量动作栏、对比模式（选 2 至 5 个对象并排对比）。
8. **导出**：服务端导出任务。

### 详情页

- 以**独立路由页面**为主，地址可分享；抽屉仅作快速预览，提供"打开完整详情"。
- 结构：
  1. **身份区**：对象标识、图片（如有）、状态标签、4 至 6 个关键指标、数据新鲜度、主动作、关注按钮。
  2. **建议动作区**：基于规则的建议，每条带依据、预估影响、执行入口（详见 3.4 第 7 项）。
  3. **页签区**：每个页签由指标卡、图表、关联表、时间线组合。
  4. **右侧关联栏**（可折叠）：关联对象、评论与协作、最近变更。
- 禁止展示原始数据结构或"字段名加字段值"网格。

### 数据状态（每个页面必须实现）

| 状态 | 展示 |
|---|---|
| 首次加载 | 骨架屏 |
| 未授权 | 需要授权的数据域、授权入口 |
| 无权限 | 缺少的权限、可联系的管理员 |
| 资格不足 | 缺少的亚马逊角色或资格、说明 |
| 无数据 | 数据域说明、前置条件、同步按钮、最近任务状态、失败原因、处理入口 |
| 数据延迟 | 最近成功时间、预计恢复时间 |
| 局部同步失败 | 失败数据域、影响范围、重试 |
| 服务端错误 | 错误编号、请求编号、重试 |
| 部分数据可用 | 可用与不可用部分的清单 |

### 全局范围栏

- 维度：法律主体、店铺、站点（固定美国站）、时间范围（含对比期：上一期、去年同期、自定义）、币种显示口径（原币、美元）。
- 与地址栏同步；列表、图表、详情、导出全部继承。
- 未完成企业初始化时显示引导页。

### 动作守卫

每个动作按顺序判断：权限 → 连接状态 → 写入开关 → 数据条件 → 预览确认。任一不满足即禁用并说明原因，有权限者显示"前往开启"或"前往处理"。执行结果以服务端返回为准，异步任务显示任务进度并在完成后通知。

### 预警、待办、通知

- 预警规则命中 → 预警实例；需人处理 → 待办（可指派、确认、忽略、关闭）；指派、到期、状态变化 → 站内通知（先轮询，后续升级推送）。
- 全部动作写审计。

### 指标口径

- 每个指标有统一定义、公式、来源、刷新频率、口径版本；鼠标悬停指标名即显示；汇总页 `/app/help/metrics`。

## 3.3 商业高端标准

| 维度 | 标准 |
|---|---|
| 视觉 | 浅色主题；主色 `#2b57cf`；文字、边框、成功、警告、危险色对齐官网；数字使用等宽数字；正负色语义全站统一；金额始终带币种，时间始终带时区 |
| 密度 | 紧凑模式；表格行高 36 至 40 像素；指标卡一行 5 至 7 个；首屏即见关键数字 |
| 层次 | 每页只有一个视觉焦点（通常是核心指标或建议动作）；次要信息折叠 |
| 性能 | 交互反馈 200 毫秒内；列表首屏 1 秒内（读汇总表）；大表滚动无卡顿；图表懒加载 |
| 一致性 | 同一指标在所有页面同名、同口径、同格式；同一对象在所有页面同一种链接与悬停卡片 |
| 可达性 | 键盘可达；对比度达标；所有图标有文字提示 |
| 专业感 | 每个数字可追溯；每个估算标注"模型估算"及方法；每个空态给出下一步 |
| 输出 | 经营日报可导出为排版好的文件；所有图表可下载 |

## 3.4 先进能力框架（超越头部 ERP，所有详情页复用）

头部 ERP 已普遍具备：多维报表、同比环比、补货建议、利润报表、广告规则与分时、运营日志、告警推送。本方案在此之上统一提供以下 12 项能力，每项都基于真实数据源。

| 编号 | 能力 | 说明 | 数据依据 |
|---|---|---|---|
| 1 | 数字可追溯 | 点击任一数字，弹出口径、公式、来源接口或报告、来源记录（可跳转）、同步时间、数据质量标记 | 全部同步表的来源字段 |
| 2 | 双源核对 | 关键数字同时显示"我方计算"与"亚马逊官方"，差异超过阈值标注并分解原因 | 单品经济数据、官方补货建议、结算、账户扣款、广告账单 |
| 3 | 事件标注时间轴 | 所有趋势图自动叠加事件：改价、改预算、改竞价、刊登变更、他人修改详情页、断货与恢复、促销起止、货件到仓、评论主题变化、账户状态变化、费用调整 | 我方操作审计、推送事件、同步差异 |
| 4 | 前后对照分析 | 对任一操作或事件，自动生成"前 N 天对后 N 天"对照，并给出同期大盘变化作为参照，避免把整体波动误判为操作效果 | 日汇总表 |
| 5 | 指标树归因 | 核心指标变化自动分解：销售额 = 会话 × 转化率 × 件单价；利润按利润桥逐项分解；广告花费按点击 × 单次点击成本分解。按贡献排序给出主因与证据链接 | 日汇总表、业务报告、广告报表 |
| 6 | 预测与模拟 | 销量预测带低、中、高区间；价格、预算、补货量、发往上游仓储的模拟器。官方模拟优先（单品经济模拟、活动预测、推荐报价预期价格），我方模型补充；结果统一标注"模型估算" | 数据中心模拟、广告活动预测、定价接口 |
| 7 | 建议动作区 | 每条建议含：触发规则、证据、预估影响（区间）、风险、执行入口（经动作守卫）；执行后自动进入前后对照 | 规则引擎 + 上述数据 |
| 8 | 协作 | 对象级评论、@成员、关注、订阅变化、指派、处理记录 | 我方数据 |
| 9 | 历史快照对比 | 任选两个日期对比对象状态：刊登内容字段级差异、价格、库存结构、广告设置 | 快照表 |
| 10 | 近实时层 | 小时级销售、流量、可售数量推送与 15 分钟级广告数据驱动"今日"视图，标注"实时估算，以日终数据为准" | 小时级推送、营销数据流第二版 |
| 11 | 运营日志 | 自动记录系统内与亚马逊侧可识别的变更，支持手工补充工作记录；与事件标注、前后对照联动 | 审计、变更记录、推送 |
| 12 | 智能问答（随后再做，不在本次范围） | 预留：基于指标口径字典的自然语言只读查询；写操作只生成草稿，必须人工在页面确认；不把买家个人信息发送给任何模型 | 指标口径字典 + 汇总表 |
