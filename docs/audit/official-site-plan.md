# 官网方案：领星的栏目 + 阿里云的做法

核对日期：2026-10-19。领星依据是 https://www.lingxing.com/ 渲染后的首页 DOM，以及价格、关于、案例、资讯、帮助、预约这几个内页。阿里云的尺寸和滚动、手风琴做法仍以 docs/audit/aliyun-homepage-reuse-spec.md 为准。

这套方案做的是公司官网。ERP 里的订单表、财务表只作为某一屏的配图，不作为首页结构。

## 1. 领星官网实际有哪些东西

首页标题是「跨境电商 ERP」。页面却不是后台。导航和页脚把公司站点铺开了。

导航从左到右：

| 栏目 | 展开后有什么 | 真实地址 |
| --- | --- | --- |
| 产品 | 四条产品线，每条一个名字加一句定位：亚马逊 ERP、多平台 ERP、海外仓 WMS、跨境物流 TMS。旁边一块「2 分钟了解」视频，再加一篇专题 | /summary、/solutions/platform |
| 价格 | 单独一页，不塞进产品里 | /price |
| 案例 | 案例中心 | /case |
| 资源与支持 | 资讯、活动、白皮书、帮助中心、一篇「为什么需要 ERP」 | /article、/activity、/whitepaper、/help/index、/topics/1.html |
| 关于 | 公司介绍、新闻、加入我们 | /about、/news、/join |
| 语言 | 中文 / English | 头部右侧 |
| 登录 | 跳到 erp.lingxing.com，离开官网 | 外链 |
| 免费试用 | 跳到注册，和登录分开 | 外链 |

首页从上到下的元素，类名来自渲染结果：

1. 首屏 lx-banner-container。桌面横向：左文右图。手机改成上下，字居中。眉题一句，主标题里关键词用 hight-light。说明里再嵌两个被强调的数字（70 万+、40+）。两个按钮：立即免费试用、查看成功案例。按钮下面是 source-tip，写明数字出自哪份报告。右图可点开视频层。
2. 客户标志跑马灯。容器写着 --duration: 90s，在首屏下方向左循环。内容是客户标志，不是功能图标。
3. 八张 core-card。图标、标题、一句。这是目录，不是详情。
4. 往下每一张卡展开成一章。一章里是产品界面图、三到四条要点、一句结果。章与章之间插一条横条：「领星 ERP，助力实现精细管理和业务增长」加按钮「立即体验功能」。有的章带视频层。
5. section-reason。三张原因卡，用 Swiper。每张有一个大数字（10+、0.1s）、一个标题、两句说明。回答「为什么选这家公司」，不回答「按钮在哪」。
6. case-module-box。又一个 Swiper。单卡宽约 251px，间距 15px。上图 bg-cover，下区有客户标志、两行标题 twoLines、三行摘要 threeLines、一个「查看详情」。点进去是 /case/编号.html。
7. 认证墙。两排徽章：亚马逊合作身份，以及高新、等保、ISO、专精特新。
8. 页脚上的收束条 footer-banner。一句结果，两个动作：获取报价、咨询。
9. 右侧悬浮：客服在线、演示、微信、电话。底部再重复售前电话、售后电话、邮箱、地址。
10. 页脚栏目：跨境资讯、活动、白皮书、解决方案（业财一体、系统集成）、案例中心、关于、以及旁路产品（星拓广告、物流追踪、跨境客服、跨境支付）。最底一行是版权、ICP、公网安备、地址。

内页各自是一种模板，不是首页的缩小版。

价格页 /price 先给四个购买承诺（60 天退款、顾问实施售后、15 天迭代），再放版本对比，下面是一组购买问题：多少钱、支持哪些平台、怎么买、数据安不安全、培训收不收费、能不能退、适合谁、会不会关联店铺、没有程序员能不能用、和别的软件有何不同。问题按「购买」和「产品功能」分组。

关于页 /about 是公司叙述：哪一年成立、做什么、总部在哪、服务网络、融资、四个数字、产品家族、年表、投资方、资质、办公室照片和城市列表。每个办公室有地址和电话。

案例页 /case 是故事列表。一条故事有行业、客户名、一句结果、一篇正文。正文结构固定：客户是谁、遇到什么、用了哪几块能力、引用一句原话、旁边再推荐几篇。

资讯页 /article 是公司新闻和行业文章，带日期。帮助中心 /help/index 按版本更新列文档。预约页 /demonstrate 单独存在，不和登录混在一起。

## 2. 有结构、先不填内容的部分

领星有、但 NOVA 现在没有事实支撑的，栏目可以留位置，内容先不写：

- 市占率、客户数量、服务中心数量
- 客户标志、客户原话、案例故事
- 亚马逊 SPN、广告合作伙伴、TSPN 这类徽章
- 高新、等保、ISO、专精特新
- 免费试用、免费版、退款天数
- 英文站
- 招聘、活动、白皮书、融资年表
- 旁路产品（广告代运营、支付、物流公司）
- ICP 和公网安备

这些位置不要改用 ERP 表格填上。空的时候改成第 4 节写的替代内容。

## 3. 做法从哪边拿

领星决定一页里有哪些栏目、每栏写什么。阿里云决定这一栏怎么排、怎么动。

| 领星的栏目 | 用阿里云的哪种做法 |
| --- | --- |
| 导航展开层 | 左摘要 264px，产品项图标 36px，说明一行省略 |
| 首屏 | 左文右图，底下一排用竖线切开 |
| 标志跑马灯的位置 | 跑马灯两侧淡出。没有客户标志时，滚的是经营环节 |
| 八个功能入口 | 12 列栅格，间距 24px，图标 40px，标题 18px，说明两行 |
| 功能长章节 | 左图右清单，用分割线，不每张卡一块阴影 |
| 章与章之间的体验条 | 整宽玻璃条，左一句、右一个按钮 |
| 为什么选择 | 四个数字横排，大字用渐变，下面一行说明 |
| 案例卡 | 手风琴：左 1 右 2，收起 64px，展开 284px |
| 认证墙的位置 | 三列分割线格子，行高 84px，放说明不放徽章 |
| 资讯三条 | 标题 18px，说明一行 |
| 收束和页脚 | 栏目标题 14px / 600，链接 14px / 行高 24 |

页面宽度用阿里云的算法：桌面左右 80px，最大内容不超过 min(1920px, 100vw) 减去 160px。手机左右 16px。1056px 以下改成单列。标题 44px / 行高 64，手机 26px / 行高 40。

## 4. NOVA 官网的栏目

导航只保留公司站点该有的入口：

产品、方案、价格、安全、资源、关于、登录、预约演示。

登录进 /login。预约进 /contact。两个按钮分开放。

| 页面 | 这个页面回答的问题 | 内容从哪来 | 现在缺的 |
| --- | --- | --- | --- |
| 首页 | 这是谁的网站，软件帮公司看清什么 | 第 5 节 | 按新顺序重排 |
| 产品 | 软件管哪些经营环节，明确不管什么 | 店铺、订单、退货、财务、广告、权限的对外说明 | 每页改成「问题、三要点、一张图、一个边界」 |
| 方案 | 不同公司阶段怎么用 | 单公司、多公司、月结、广告另授权、成员分工 | /solutions 按场景写 |
| 价格 | 怎么买，买到什么，不买到什么 | 两档范围：1 到 5 店、6 到 20 店。实施和定制另计 | 补购买问答，仍然不写人民币 |
| 安全 | 数据放哪、保存多久、谁能看 | 公司配置里的地区、30 天删除、权限码 | 用说明卡 |
| 资源 | 想先看懂再联系，去哪 | 帮助问答、隐私、条款、安全 | 不做活动、白皮书、英文 |
| 关于 | 公司是谁，在哪，怎么联系 | 法律名称、地址、电话、邮箱 | 不写融资、客户数、分店 |
| 预约 | 留下公司和店铺规模 | 现有表单 | 不收集亚马逊密码 |
| 案例 | 别人怎么用 | 无 | 没有授权客户就不做这一页 |

产品页的章节顺序按买家理解：

1. 多家公司怎么分开授权
2. 订单属于哪家公司、哪个站点
3. 退货怎么对回原来的月份
4. 财务为什么不能把不同币种加在一起
5. 广告账户为什么要再授权一次
6. 成员为什么不能看见所有公司

每一章固定四段：一句问题、三条要点、一张标着「示例」的界面、一句做不到的事。做不到的事包括：不代替完成应用审批，不保证接口一定可读，广告不改出价，不做代运营。

## 5. 首页按这个顺序排

一共十屏。方向每屏换一次。

屏 1，首屏。左文右图。眉题「亚马逊经营数据」。主标题「多家公司，分开看清」。说明一句：店铺、订单、退货和财务按法律主体查询；广告账户单独授权，未授权不显示花费。按钮「预约演示」「看方案」。右图是产品窗口。图角标「示例」。

屏 2，横条。四段竖线。店铺、订单、财务、广告。每段一个标题、两行说明，整段可点。对应 /product/stores、/product/orders、/product/finance、/product/advertising。

屏 3，环节条。占领星客户标志的位置。向左缓慢滚动六个词：主体、店铺、订单、退货、财务、权限。

屏 4，目录。六个入口，图标 40px，标题 18px，一句说明。点进去到对应产品章，不打开后台。

屏 5，第一章。左图右四条勾选。标题「每家公司单独授权」。四条：法律主体下登记卖家账号；卖家账号再对应站点；连接记录授权和最近同步；查询带租户条件。按钮「查看店铺」。

屏 6，玻璃条。左句「广告和卖家授权不是同一件事。」右按钮「看广告方案」，去 /solutions/advertising。

屏 7，第二章。分割线两列。左：退货对回原订单月份。右：同一币种才计算净额。每边一张示例图、三行要点。

屏 8，为什么找这家。四个格子：1–5 店、6–20 店、30 天、只读。30 天必须和隐私政策同一句。下面三张原因：软件按法律主体查询；买家信息按政策删除；电话、邮件、地址公开。

屏 9，场景。手风琴，默认展开第一条。五条：三家公司一起查、退货对月、财务分币种、广告只读、成员权限。右边大图跟着换。不出现客户名。

屏 10，收束。一句「预约一次演示」，一个按钮。下面四行从公司配置读：电话、邮件、地址，以及不代替审批、不保证接口一定可读。页脚栏目：产品、方案、价格、安全、资源、关于、隐私、条款。没有备案号就不渲染备案行。

右侧保留四个入口：电话、预约、邮件、回到顶部。不放在线客服，除非真的有人值守。

## 6. 价格页和关于页要补的块

价格页用领星的问题清单，改成现在能回答的：

1. 费用怎么算。按法律主体和店铺规模报价，页面不标人民币。两档范围写清楚。
2. 怎么开始。提交预约，或拨打公司电话。不提供自助开通。
3. 买到什么。方案里写明工作台范围、授权后的查看方式、成员权限，以及订单、退货、财务是否包含。
4. 不包含什么。现场实施、额外定制、更高同步频率另计。人工广告代运营不在内。
5. 数据放在哪、保存多久。与隐私政策同一套句子。
6. 没有开发人员能不能用。查询在网页里完成。应用审批仍由企业自己向亚马逊提交。
7. 广告和店铺是不是一起开通。不是。广告账户要单独授权。

关于页只放四块：公司全称和一句业务、地址电话邮箱、产品是一套查询软件、隐私和安全的入口。办公室照片、城市列表、年表，有真实材料再加。

资源页放三列：常见问题、隐私与条款、安全说明。常见问题用价格页和产品页已经写过的句子。
