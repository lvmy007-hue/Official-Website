# 阿里云首页：方向、做法、内容怎么落地

核对日期：2026-10-19。依据是 `https://www.aliyun.com/` 渲染后的 DOM、页面引用的样式包，以及长截图。文案按页面从上到下的可见文字整理，共 177 条。下面每一屏都写三件事：眼睛往哪走、用什么手法做出来、每个字段写多长、NOVA 该填哪句。

NOVA 只复用版式和字段，不复用阿里云的价格、模型名、客户名、市场份额和认证。

## 0. 整页先定这几条，否则做出来还是一叠卡片

页面宽度：

```css
--page-margin: 80px;          /* 手机 16px */
--screen-max-width: min(1920px, 100vw);
width: calc(var(--screen-max-width) - var(--page-margin) * 2);
margin: 0 auto;
```

断点只有一条业务分界：`min-width: 1056px` 是桌面，`max-width: 1055px` 是手机。主题里另外记了 601 / 1281 / 1921，首页模块实际切换用的是 1056。桌面和手机是两套 DOM，用 `.pc` / `.mobile` 互斥 `display: none`，不是同一棵树硬挤。

字号只走这一档，标题不要再自己发明：

| 用途 | 桌面 | 手机 |
| --- | --- | --- |
| 屏标题 h2 | 44px / 行高 64 / 字重 600 | 26px / 行高 40，居中 |
| 屏内小标题 h3 | 26px / 行高 40 / 600 | 同上 |
| 卡片标题 h4 | 18px / 行高 28 / 600，一行省略 | 16px |
| 正文 | 14px / 行高 24 | 14px |
| 按钮 | 高 44px，左右 24px，14px / 500，圆角 8px | 同左 |
| 标签 | 高 20px，12px / 600，圆角 4px | 同左 |

颜色：正文 `#191c21`，次级正文 `#2d3238`，产品说明在产品体系里降到 `#999`，主色 `#1366ec`。卡片圆角 16px，大面板 24px。屏与屏的间距是 56px（`spacing-14`），手机降一档。

栅格默认 12 列，间距 24px，手机间距 16px。格子用 `--col` / `--row` 决定跨度，手机用另一套 `--mobile-col`。需要“表格感”时不画卡片阴影，把 `gap` 设为 0，用 `1px #E0E0E0` 的分割线变量把格子隔开。

一屏只允许一种运动方向。下一屏必须换方向。阿里云首页的方向是按这个顺序换的：

1. 左文右图，底下一条横条从左读到右
2. 左边钉住，右边向上滚
3. 左图右清单，格子靠分割线而不是阴影
4. 整宽玻璃条，左文右入口
5. 左分类、右内容，和上一块方向相反
6. 左手风琴、右大图，高度展开
7. 深色横条，四个优惠从左到右
8. 客户标志格子，再接一条案例
9. 四个数字横排
10. 收束：大图居中，下面服务行

内容字段全站统一，不允许一段屏里又写长文：

- 屏标题：两句，一共 12 到 22 个汉字。第一句说对象，第二句说结果。可以只把第二句做成渐变字。
- 一句说明：40 到 70 个汉字，只讲一件事。
- 勾选行：16 个汉字左右，一行一条，最多 4 条。
- 卡片：图标、标题、可选标签、两行说明、一个链接。
- 一屏最多两个按钮。主按钮是动作，次按钮是咨询或目录。其余屏只有一个文字按钮，放在标题右侧或标题下方。

零件只有六种，后面所有屏都用它们拼，不为一屏新写一种左右栏：

- `Box`：容器。背景图用变量 `--background-image`，手机用 `--mobile-background-image`。
- `Grid`：12 列。单元格写 `--col`。
- `Typography`：只负责一个标题或一段正文。
- `Image`：图铺满格子，`object-fit` 由父级决定。
- `LinkBox`：整张可点。底层是绝对定位的图或视频，内容层是相对定位，这样字可以压在图上。
- `LinkButton`：44px 高的文字按钮，右侧一个 18px 箭头。

悬停和入场也是统一的，不每张卡各做一种动画：

- 链接颜色过渡 `0.3s`。
- 手风琴只动画 `height`，`0.3s`。
- 视频默认透明，悬停类 `adc-hover` 加上后立刻显示，离开用 `0.3s` 淡出。
- 进入视口的块带 `adc-slideup`。
- 聚光灯把鼠标位置写成 `--mouse-x`、`--mouse-y`，默认 `-1000px`，离开卡片就回到屏幕外。

## 1. 首屏：左文右图，底下横条

方向：标题在左，场景图在右。读完两个按钮，眼睛沿底下一排从左扫到右。底栏不是四张浮起的卡片，是一条被竖线切开的横条。

做法：

- 上半 `display: flex`。左是标题组，右是一张 `3072×1512` 的场景图。
- 标题拆成两截。普通字是产品名，渐变字是两个字的结果。渐变是 `75deg`，从 `#BAACFF` 到 `#6D54EB`、`#2B67EE`、`#6BBFFF`，用 `background-clip: text`。
- 两个按钮并排。主按钮实心，次按钮是玻璃：白到半透明的双层渐变、`backdrop-filter: blur(40px)`、圆角 8px。
- 底栏四项 `flex: 1`。第二项起 `padding-left: 65px`。竖线用 `::before`，`left: 32px`，`border-left: 1px solid #e8e8e8`。第一项没有左内边距，也没有竖线。
- 图标不是单独的 SVG。它是一张 `2304×64` 的精灵条，盒子 32×32，`background-size: auto 32px`，变量 `--steps: 35`、`--duration: 1.5s`。动画把 `background-position-x` 从 `0` 走到 `calc(-32px * var(--steps))`。手机图标放大到 40×40，文字改到图标右边，`margin-left: 20px`。
- 底栏标题 18px / 600 / 行高 28，单行省略，距图标 20px。说明 14px / 行高 24，颜色 `#999`，最多两行。整条是一个链接。
- 手机：上半改成上下堆，竖线改成每项的顶边框，内边距 `25px 0 24px`。

内容怎么写：

| 字段 | 阿里云写法 | 字数 | NOVA 填什么 |
| --- | --- | --- | --- |
| 普通标题 | Token Plan | 产品名 | 多公司经营 |
| 渐变两字 | 全面升级 | 2 到 4 字 | 分开看清 |
| 一句说明 | 价格不变、权益加码，覆盖模型、工具、编排 | 40 到 70 字 | 多家公司的店铺、订单、退货和财务按法律主体分开查询。广告账户要单独授权，未授权不显示花费。 |
| 主按钮 | 立即订阅 | 4 字 | 预约演示 |
| 次按钮 | 在线咨询 | 4 字 | 看产品 |
| 横条 1 标题 | 模型名 + 能力 | 含一个具体能力 | 法律主体与店铺 |
| 横条 1 说明 | 能处理什么 | 两行以内 | 每家公司单独授权，店铺才进入可查询范围。 |
| 横条 2 | 带价格的产品 | 标题里有数字 | 订单 |
| 横条 2 说明 | 规格 | 两行 | 按卖家账号保存购买时间、状态、币种和来源更新时间。 |
| 横条 3 | 带价格的产品 | 同上 | 财务结算 |
| 横条 3 说明 | 规格 | 两行 | 收入、退款、费用按同一币种排列，不同币种不相加。 |
| 横条 4 | 旗舰能力 | 同上 | 广告分析 |
| 横条 4 说明 | 结果 | 两行 | 广告账户单独授权。报表只读，不改出价。 |

横条必须链到已有路由：`/product/stores`、`/product/orders`、`/product/finance`、`/product/advertising`。不要写「99 元」「免费额度」这类阿里云自己的报价。NOVA 价格页是报价，不出现人民币数字。

## 2. 双栏滚动：左图钉住，右列上移

方向：滚动时眼睛停在左边的大图，右边的条目从下方进入、向上离开。这是整页里唯一一段「内容比视口高」的屏。右边条目不够一屏，粘性就看不出来。

做法：

- 只在 `min-width: 1056px` 启用。容器 `display: grid`。
- `.background` 和 `.foreground` 都是 `grid-area: 1 / 1`。
- 背景内层 `position: sticky; top: 0; height: min(100vh, 100%)`。背景图是变量里的一张 `2880×1666` 场景图，`background-size: 100% 100%`。
- 前景是 12 列、间距 24px，`pointer-events: none`。内容 `--column-start: 7; --column-end: 13`，占右半，自己 `pointer-events: all`。
- 左边另有一个 Grid 单元格 `--col: 6`，用来放标题和按钮，和粘性图叠在同一区域。标题是 h2，按钮一个：「立即免费体验」。
- 右边每一条是一张 LinkBox：分类眉题、`产品名 | 能力`、一句说明。图在卡片里，不在左边。

这一屏抓到的六条是：大语言模型、视频生成、智能建站、分析 Agent、智能运维、AI 数据集成。结构都一样。

```css
.sticky-split { display: grid; }
.sticky-split .stage,
.sticky-split .rail { grid-area: 1 / 1; }
.sticky-split .stage-inner {
  position: sticky;
  top: 0;
  height: min(100vh, 100%);
}
.sticky-split .rail {
  display: grid;
  grid-template-columns: repeat(12, minmax(0, 1fr));
  gap: 24px;
  pointer-events: none;
}
.sticky-split .rail-inner {
  grid-column: 7 / 13;
  pointer-events: auto;
  display: grid;
  gap: 16px;
}
```

内容怎么写。每条三行，不要再加表格：

| 眉题 | 产品 \| 能力 | 一句说明 | NOVA 链接 |
| --- | --- | --- | --- |
| 店铺 | 法律主体 \| 单独授权 | 卖家账号登记在法律主体下面，再对应站点。 | `/product/stores` |
| 订单 | 订单记录 \| 时间、状态、币种 | 汇总数字看不出属于哪家公司、哪个站点、哪一天。 | `/product/orders` |
| 退货 | 跨月退货 \| 对回原订单 | 本月收到的退款经常来自更早的订单。 | `/product/returns` |
| 财务 | 结算 \| 同币种才相加 | 美元订单和欧元费用不能合成一个净额。 | `/product/finance` |
| 广告 | 广告账户 \| 只读报表 | 花费、点击、销售额按账户币种看。未授权不展示成绩。 | `/product/advertising` |
| 权限 | 成员 \| 权限码 | 登录成功不等于可以查看所有公司的数据。 | `/product/permissions` |

左图用一张多层产品窗口，窗口里是示例数据，角上标明「示例」。不要放真实订单，也不要放阿里云那种模型海报。

## 3. 能力屏：左图，右四条勾选，下面用分割线铺模型卡

方向：先读中间的大标题，再看左边产品截图，右边从上到下读四条勾选和一个按钮。再往下，卡片从左到右、从上到下，两列，中间是线不是缝。

做法：

- 标题是 h2，44px，下边距 56px。阿里云这句是「千问大模型，企业拥抱 AI 时代优选」。字是逐字包起来的，方便做渐变或入场，内容本身仍是一句话。
- 上面一行 Grid：左格 `--col: 4`，放一张 `1248×1152` 的产品界面图。右格放标题「千问大模型」、四条勾选、一个按钮「访问模型市场」。
- 勾选是横排：16px 的主色对勾，正文 `14px / 24`，颜色用次级色，左边距 4px。行距 `mt-1-5`。
- 下面模型区 Grid：`row-height: 194px`，每格 `--col: 6`，所以一行两张。`gap: 0`，分割线 `1px #E0E0E0`。
- 每张卡：40×40 图标，标题 h4 `18/28` 一行省略，旁边一个高 20px 的标签，说明两行。悬停时铺一层 `rgba(0,98,255,.05)` 的斜向渐变，平时这层是 0。
- 最后一条证明单独放，不放进勾选里。阿里云写的是「AI 云市场份额超过 2-4 名总和」。NOVA 没有这个事实，这行留空。

内容怎么写：

屏标题用两句：「一家公司一套授权，多家公司放在一起查。」

左图对应「法律主体与店铺」的界面，不要用抽象插画。

四条勾选直接用现有功能句，每条不超过 18 个字：

1. 法律主体下登记卖家账号
2. 卖家账号再对应站点
3. 连接记录授权和最近同步
4. 查询带租户条件

按钮文案：「查看店铺」，链到 `/product/stores`。

下面六张分割线卡片，对应六个已有模块。字段是图标、标题、一行标签、两行说明：

| 标题 | 标签 | 说明 |
| --- | --- | --- |
| 法律主体与店铺 | 已建模 | 每家公司单独授权，店铺才进入可查询范围。 |
| 订单 | 按账号 | 保留购买时间、状态、币种和来源更新时间。 |

## 4. 平台条：整宽玻璃，左文右入口

方向：横向。左边两行字加一个按钮，右边一排小入口。它是上一屏的收束，不是新的一章。

做法：

- 容器 `rounded-card-lg`（24px）、`w-page`、`shadow-small`、`backdrop-blur-10`。
- 左：h3 26px，一句 14px 说明，一个 44px 按钮。
- 右：入口横排。图标 28×28，标题 16px，一行说明。每个入口是 LinkBox。
- 阿里云左文是「千问 AI 平台，模型触手可及」，按钮「前往千问 AI 平台」「查看详情」。右边是免费额度等入口。

NOVA 左文：「工作台按法律主体查询。」说明：「订单、退货、财务是否包含，在方案里说明。人工广告代运营不在服务内。」按钮：「看方案」，链到 `/solutions`。右边三个入口就够：`/pricing` 报价范围、`/product/advertising` 广告只读、`/contact` 预约。不要做第四个「免费试用」。

## 5. 产品体系：左分类钉住，右内容换

方向：和滚动屏相反。这次是左边固定一列名字，右边整块内容跟着换。眼睛先在左列上下找分类，再在右边从主推读到普通项。

做法：

- 整块 `min-height: 602px`，横向 flex。
- 左列宽 `215px`，右边距 `36px`。每项高 `52px`，字号 `18px`，左右内边距 `24px`，项与项上边距 `4px`。
- 选中条是分类容器的 `::before`：高 52px，圆角 12px，`top: calc(var(--top-index) * 56px)`，过渡 `top .3s`。字重同时过渡 `0.3s`。
- 手机把左列隐藏，改成顶部横滑标签。标签高 32px，字号 14px，项间距 36px。下划线高 2px、颜色 `#1366ec`，位置用 `--underline-left` 和 `--underline-width`，过渡 `0.3s`。
- 右板：`flex-grow: 1`，内边距 12px，圆角 24px，白到透明的渐变，`backdrop-filter: blur(40px)`。阴影是 `0 3px 12px -2px #0000000d`、`0 12px 48px -10px #1366ec1c`，再加内高光 `inset 0 0 28px #ffffff80`。
- 主推 3 列，行高写死 `176px`，列间距 `12px`。单卡内边距 `24px`，圆角 `16px`。标题 18/28/600，说明 14/24/`#999`，都单行省略。主推有两个动作：主按钮最小宽 127px、高 40px、左右 20px，右侧用边框画一个 6px 的箭头；次动作是文字。
- 普通项：3 列 4 行，行高 `84px`，间距 `12px 24px`，整块高 `390px`。只有标题和一句说明，没有按钮。
- 手机主推行高 148px，普通项改 2 列、行高 112px。

阿里云左列九个分类：精选产品、人工智能与机器学习、计算、存储、网络与 CDN、安全、中间件、数据库、大数据计算。右上三张主推是云服务器、千问、百炼，各有两个动作。下面十二个只有名称和一句。

NOVA 没有九个产品线。左列只放真实分类，三项就够：

| 分类 | 主推（有两个动作） | 普通项（只有一句） |
| --- | --- | --- |
| 经营数据 | 店铺、订单、财务 | 退货、权限 |
| 广告 | 广告分析 | 广告和卖家授权分开、报表失败会留下失败状态 |
| 交付 | 单公司起步、多公司 | 报价不含代运营、不含保证接口一定可读 |

主推的两个动作统一写成「查看模块」和「预约」。普通项的说明用 `productAreas` 里的 `claim`，每句不超过 32 个字。不够 12 个就不要凑假产品。右板允许下面留白，不要把格子填满。

分类切换只换右板内容，左列不滚动。`--top-index` 从 0 开始。

## 6. 方案手风琴：左列展开，右图占两倍宽

方向：标题横在上面，按钮在标题旁。下面左窄右宽。左边一次只展开一条，右边的大图跟着换。读的是「点一条，看一张场景」，不是五张并排卡。

做法，尺寸来自 `homepage-ai-solution`：

- 面板高 `572px`，内边距 `12px`。手机整块面板 `display: none`，另有一套 `.h5-panel`。
- 左 `flex: 1`，右 `flex: 2`。
- 展开项高 `284px`，内边距 `24px`，过渡 `height .3s`。背景 `#fff9`，模糊 40px。第一项上圆角 12px，最后一项下圆角 12px，项间距 2px。
- 收起项高 `64px`，只留标题。标题 18px / 500 / 行高 28。说明和按钮放在会被高度裁掉的区域里，不要用 `display: none` 硬切，这样高度动画才连续。
- 展开后显示一句说明，加两个动作：「了解详情」「联系 AI 专家」。
- 右侧是场景。视频铺满，`object-fit: contain`。封面图绝对定位盖在视频上，透明度 `0.5s`。播放钮 64×64，白色圆，居中，悬停变 `#1366ec`。
- 桌面展开用 `opacity` 加 `fadeIn .3s`。收起是 `opacity: 0` 且 `pointer-events: none`。手机收起项直接 `display: none`。

阿里云五条的写法都是「场景名 + 一句能完成的事」：分析 Agent、漫剧工坊、实时音视频、10 分钟加助手、多模态提取。说明大约 40 到 60 字。

NOVA 五条用现有场景，不要编客户：

| 标题 | 说明 | 右图画什么 | 链接 |
| --- | --- | --- | --- |
| 三家公司放在一起查 | 每家公司单独授权。未审批的连接停在等待，不显示成已同步。 | 主体列表，两家已连接，一家等待 | `/solutions` |
| 退货对回下单的月份 | 本月入账的退款保留退货日期和原订单号，不并进当月销售额。 | 月份对照表，标注示例 | `/product/returns` |
| 财务只在同一币种里算净额 | 费用事件有入账时间和结算编号。页面没有自动汇率。 | 分币种的费用表 | `/product/finance` |
| 广告报表单独授权 | 账户、花费、点击、广告销售额按广告授权读取。不改出价，不做代运营。 | 广告指标卡，标注示例 | `/solutions/advertising` |
| 成员看不到全部公司 | 运营、财务、广告使用不同权限码。没有成员关系时接口拒绝。 | 权限码列表 | `/product/permissions` |

默认展开第一条。右图是界面截图，不是海报。没有视频就只放静图，不要放一个不能播放的播放钮。

## 7. 权益横条：深底，四个短优惠

方向：从左到右扫四个「数字 + 一句」。它是促销，不是功能说明。没有这一屏，页面会在手风琴后面突然结束。

做法：标题 h2 在深色渐变底上，白色。下面 4 到 8 个入口，每个是图标或数字、一句优惠、一个链接。阿里云写的是「39 元起」「4.5 折」「300 元」「9.9 元」「160+ 产品免费试用」。

NOVA 不能写这些价格。这一屏改成两个真实方案，横排放，不加第三张凑数：

| 名称 | 范围 | 包含 | 链接 |
| --- | --- | --- | --- |
| 单公司起步 | 1 个法律主体，1–5 个店铺 | 订单、退货、库存、财务、成员权限 | `/pricing` |
| 多公司 | 3 个法律主体，6–20 个店铺 | 上面的范围，另加广告报表分析 | `/pricing` |

每张下面一行小字：「现场实施、额外定制和更高的同步频率另行计算。」不要出现人民币。

## 8. 客户与标志：格子，不滚动卡片

方向：标题后先是一整面标志墙，再是一条被选中的案例。标志是扫过去的，案例才是读的。

做法：

- 标题「AI 赋能千行百业……」，右侧按钮「全部客户案例」。
- 标志墙由 `UseTerminal` 包一层，里面 Grid 被改成 3 列，`row-height: 56px`，`gap: 0`，分割线 `1px #E0E0E0`。每个格子是一张 `320×80` 的标志，`background-size: contain`，居中。
- 标志墙后面还有跑马灯零件：时长 `--duration: 30s`，左右各 200px 的透明遮罩。首页客户区这次用的是格子，不是跑马灯。跑马灯留在导航或合作方一行再用。
- 案例正文是一段 50 到 80 字的事实，旁边一个行业标签，例如「巴黎奥运会」「信息技术」。

NOVA 没有可公开的客户名和标志。这一屏不要做。不要用虚构公司填 56px 的格子，也不要写「已服务多少家」。等有书面授权的客户后再按这个格子做。空着比编更接近亚马逊对网站真实性的要求。

## 9. 数字条：四个格子，数字用渐变

方向：横读。每个格子占 12 列里的 3 列，手机占 6 列，所以手机一行两个。

做法：数字是 h3，类名 `text-gradient-ai`。渐变是径向的，`#D0CAFF → #A06FFF → #2B67EE → #98D4FF`，`background-clip: text`。单位和名称在下一行，14px。阿里云的四个数是 31 个地域、107 个可用区、3200+ 边缘节点、180+ Tbps。

NOVA 没有这些基础设施数字。不要换成「店铺数」「同步成功率」。可以改成四个边界句，数字只用方案里已经写过的范围：

| 大字 | 下一行 |
| --- | --- |
| 1–5 | 单公司起步的店铺数 |
| 6–20 | 多公司方案的店铺数 |
| 30 天 | 买家个人信息在发货后的删除期限（与隐私政策同一句） |
| 只读 | 广告报表不改出价 |

30 天这条必须和 `site-company.ts` 里的保留期限一致。以后改政策，只改那一个字段。

## 10. 收束：大图居中，下面四行服务

方向：先看中间的大标题和主按钮，再向下读服务。服务是图标加两行字，横排，不再展开成卡片阵。

做法：

- 标题拆成两行：「立即体验」「在阿里云上创造未来」。NOVA 写成「预约一次演示」「按法律主体看店铺、订单和财务」。
- 一个主按钮「免费体验」。NOVA 写成「预约演示」，链到 `/contact`。不要写免费注册。
- 背景是基础设施图，失败时用一张 `object-fit: contain`、贴底的替图。NOVA 用同一张多层产品图的缩小版，不要再画地球。
- 标题下四行，阿里云是全天候、专属、多渠道、专业上云。每行一个小图、一个标题、一句说明。

NOVA 四行用已经公开的事实：

| 标题 | 说明 |

| 电话 | 0755-8692-1800，来自公司配置 |
| 邮件 | support@dzanx.com |

| 边界 | 不代替企业完成应用审批，也不保证卖家或广告接口一定可读 |

电话、邮箱、地址只从 `site-company.ts` 读。页脚再重复一遍，不要在组件里写死第二份。

## 11. 页脚：栏目、关注、许可

方向：从左到右是栏目，底部一条是许可和版权。

做法：

- 服务区 `flex: 4`，最小高度 180px。栏目标题 14px / 600，下边距 16px。链接 14px / 行高 24，下边距 8px，颜色过渡 0.3s。
- 二维码 62×62。关注行在上。
- 关于链接行内排列，右边距 35px。搜索框最小宽 220px、高 30px，靠右。
- 备案图 20×20，和备案号同一行。
- 手机字号降到 12px，链接改成块级，高 32px。

阿里云底部有许可证号和公网安备。NOVA 没有备案号，这一行不渲染。栏目用现在已有的页：产品、方案、广告、价格、关于、隐私、条款、安全、联系。不要加「培训与认证」「大赛」。

## 12. 按这个顺序做，不要从卡片阵开始

1. 先做页面壳：80px 边距、1056 断点、44/26 的标题、44px 按钮。旧的居中大标题和等分卡片先拿掉。
2. 做首屏左文右图加四段竖线横条。图标可以先用静态 32px，精灵条是第二步。
3. 做双栏滚动。右列用上面六条，左图钉住。列表高度必须超过一屏。
4. 做分割线两列卡，替换现在的阴影卡片。
5. 做左分类右内容。分类只有三项。
6. 做手风琴。默认展开第一条，右图跟着换。
